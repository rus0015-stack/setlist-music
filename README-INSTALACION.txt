SETLIST MUSIC — PWA
===================

ARCHIVOS
- index.html: aplicación principal
- manifest.json: configuración de instalación PWA
- service-worker.js: funcionamiento offline/cache
- icons/: iconos de la aplicación

PUBLICACIÓN GRATUITA
1. Crea una cuenta en GitHub.
2. Crea un repositorio, por ejemplo: setlist-music.
3. Sube TODOS los archivos y la carpeta icons.
4. Activa Settings > Pages > Deploy from branch > main / root.
5. Espera a que GitHub Pages publique el sitio.
6. Abre la dirección HTTPS que GitHub te entregue.

INSTALACIÓN
Android: Chrome > menú > Instalar aplicación.
Windows: Chrome/Edge > icono Instalar en la barra de direcciones.
iPhone/iPad: Safari > Compartir > Añadir a pantalla de inicio.

IMPORTANTE
La biblioteca actual se guarda localmente en cada dispositivo. Para compartir
canciones/setlists entre músicos habrá que añadir sincronización/nube en una
versión posterior.
